# Manuscript results

`paper_quality.csv` and `paper_runtime.csv` contain reported manuscript values, not new experimental outputs. Source tables and evaluation settings are included per row. Empty fields mean not reported. See [protocol and caveats](../docs/PAPER.md) before comparing scores or timings. `paper_ablations.csv` contains this model's reported component study; it does not assert that all ablated implementations/checkpoints are bundled.
